# 云成本与 FinOps 管理平台企业能力

## 领域覆盖

- **云账号管理**：统一多云账号、组织和成本中心关系
- **账单归集**：采集账单明细、价格和使用量
- **成本分摊**：按标签、组织、产品和规则分摊成本
- **标签治理**：检查标签覆盖、规范和责任归属
- **预算管理**：管理预算、预测、阈值和通知
- **费用异常**：识别突增、闲置和异常购买
- **承诺折扣**：管理预留、节省计划和覆盖利用
- **资源优化**：输出规格调整、关停和存储优化建议
- **单位经济**：关联客户、订单和产品分析单位成本

## 横向控制基线

- ADMIN 与 OPERATOR 权限分离，管理员审批由服务端强制校验；
- 模块白名单、字段约束、唯一编号、乐观锁和合法状态迁移；
- 企业控制项支持组织、期间、责任人、风险、期限和幂等键；
- 经办与复核职责分离，办结前至少登记一份带 SHA-256 的业务凭证；
- 外部系统同步保存成功、失败、回执编号和审计详情；
- 支持组合检索、分页、逾期筛选、CSV 导出、评论与时间线；
- `/api/domain/decision` 对云成本与 FinOps 管理平台关键场景返回决策、0–100评分、计算指标和处置动作；
- prod profile 对默认账号密码、数据库口令和不安全跨域来源执行启动门禁。

## 生产适配

真实 `CLOUD`、IAM、消息、对象存储和第三方供应商接口只预留集成边界，由部署企业自行配置。生产上线前必须完成权限矩阵、数据映射、容量压测、灾备演练、安全评估与用户验收。
